# Game of Life
A simple program in Python that simulates Conway's Game of Life.

The program has:
* Pausing;
* A Step-by-step simulation (when paused);
* Placing/removing cells on click;
* A limited, non-cyclic field that can be customized via code.

## Controls
[E] - makes next step when paused;

[R] - clears the field;

[SPACE] - pause/unpause;

[Left Click] - place/remove cell when paused;

[Q] - change simulation speed;

## Requirements
Pygame library.
